MOTIPE [ 지역 축제 기반 여행 추천 플랫폼 ]
"Your Motivation to the Place, MOTIPE!"
📌 프로젝트 소개
MOTIPE(모티프)는 '동기(Motivate)'와 '장소(Place)'를 결합하여 만든 이름으로, "사용자가 그 장소로 떠나고 싶게 만드는 강력한 동기를 부여하자"는 의미와 비전을 담고 있습니다.

단순히 유명 관광지만을 나열하는 것을 넘어, 전국 각지의 다채로운 지역 축제를 중심으로 매력적인 여행 정보를 제공하고 나만의 여행 코스를 계획할 수 있도록 돕는 맞춤형 여행 추천 웹 서비스입니다.
